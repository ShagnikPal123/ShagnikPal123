## 👋 About me

I'm a freshman at **Texas A&M University** double majoring in **Electrical & Computer Engineering**, in the **Honors Academy**. I like building things where hardware constraints meet machine learning, especially models that have to run on small, local devices.

- 🔬 Undergraduate research in multimodal AI, genomic ML and computational text analytics
- ⚡ Interested in edge computing and efficient on-device inference
- 🤖 Active in **IEEE** and the **turtle robotics** club at TAMU
- 🌱 Currently shipping a new small ML project in [`daily-ml-project`](https://github.com/ShagnikPal123/daily-ml-project)
